The coordinator's wire-format decoder (`coordinator/src/round/signing.rs:156-179`):
- Iterates over `psbt.unsigned_tx.input` indexed by `i`
- Builds `outpoint_str = format!("{}:{}", txid, vout)`
- Looks up `inner.partial_sigs.get(&outpoint_str)` → `Option<&Vec<u8>>` (the bytes the client sent)
- Calls `bitcoin::consensus::deserialize::<bitcoin::Witness>(sig_bytes)`:
    - `Ok(witness)` → `psbt.inputs[i].final_script_witness = Some(witness)` (success path)
    - `Err(_)` → returns `ApiError { code: BroadcastRejected, message: "Invalid witness data for input {i}", round_id }` (this is the HTTP 400 Plan 12-02 hit)

Contract Plan 13-01's encoder MUST satisfy: `bitcoin::consensus::deserialize::<bitcoin::Witness>(client_bytes)` returns `Ok(witness)` where `witness` is a 2-item P2WPKH stack `[sig_der_with_sighash_byte, compressed_pubkey_bytes]`.

<!-- The current broken state of client/src/wallet.rs lines 276-291 (READ from current HEAD): -->

Lines 276-291 currently destructure `(_pk, sig)` at line 279 (discarding the pubkey) and return `Ok(sig.to_vec())` at line 280 — that returns ~71-72 raw bytes starting `0x30 0x4N ...` (DER-encoded ECDSA sig + SIGHASH_ALL byte). The coordinator's `consensus::deserialize::<Witness>()` then interprets the leading `0x30` as a CompactInt witness-stack-item-count of 48 and fails.

<!-- The fix shape per CONTEXT.md D-01 and PATTERNS.md §"Encoding pattern" (lines 89-98). Full code excerpts live in those files; this block names the identifiers/signatures the executor uses. -->

Fix shape at lines 279-281:
- Destructure: `(pk, sig)` instead of `(_pk, sig)` — `pk` is `&bitcoin::PublicKey`, `sig` is `&bitcoin::ecdsa::Signature`.
- Build a fresh `bitcoin::Witness::new()` (fully-qualified path; no `use` change needed — verified by PATTERNS.md §"Imports pattern" lines 104-110; the file already uses inline `use` / fully-qualified paths for other `bitcoin::*` types).
- Push `sig.to_vec()` first (DER + SIGHASH_ALL — `bitcoin::ecdsa::Signature::to_vec()` from rust-bitcoin 0.32 already appends the sighash byte per PATTERNS.md §"Witness construction patterns" lines 114-132; do NOT manually `push(0x01)`).
- Push `pk.to_bytes()` second (compressed pubkey, 33 bytes).
- Return `Ok(bitcoin::consensus::serialize(&witness))` — infallible for `bitcoin::Witness`, no `?` or `map_err` needed (PATTERNS.md §"Error-handling pattern" lines 136-146).

Total diff: ~4 LOC. The `if let Some(witness) = &input.final_script_witness { ... }` fallback at lines 283-288 stays untouched per CD-3.
