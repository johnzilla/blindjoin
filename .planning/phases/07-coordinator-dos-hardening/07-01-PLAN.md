<objective>
Cache the parsed `RsaBlindSigner` in `RoundStateInner` so that RSA key deserialization (an expensive CPU operation) does not appear in the per-request hot path.

Purpose: Per-request `RsaBlindSigner::from_der_secret_key()` calls deserialize a 2048-bit RSA private key on every `POST /round/input` and `POST /round/output`. An attacker can force repeated deserialization at negligible network cost. Caching the parsed signer eliminates this vector (AVAIL-02, D-04 through D-07).

Output: `RoundStateInner` gains an `rsa_signer: RsaBlindSigner` field (non-optional since it must always be present when inner exists); handlers replace the `from_der_secret_key()` call with a direct reference to the cached field; test construction sites updated accordingly.
</objective>

pub struct RsaBlindSigner {
    pub public_key: BjPublicKey,
    secret_key: BjSecretKey,   // private
}

impl RsaBlindSigner {
    pub fn generate() -> Result<Self, blind_rsa_signatures::Error>;
    pub fn from_der_secret_key(der: &[u8]) -> Result<Self, blind_rsa_signatures::Error>;
    pub fn blind_sign(&self, blinded_msg: &BlindMessage) -> Result<BlindSignature, ...>;
    pub fn public_key_hash(&self) -> [u8; 32];
    pub fn secret_key_der(&self) -> Result<Vec<u8>, ...>;   // takes &self — signer stays live
    pub fn public_key_spki_der(&self) -> Result<Vec<u8>, ...>;
}
// NOTE: RsaBlindSigner does NOT implement Clone.
// BjPublicKey (= PublicKey<Sha384, PSS, Randomized>) DOES implement Clone.
// Confirmed: blind-rsa-signatures 0.17.1 lib.rs line 601: #[derive(Clone, Debug, Eq, PartialEq)]
// pub struct PublicKey<H, S, M> { inner: RsaPublicKey, ... }
// RsaPublicKey from the rsa crate also implements Clone (BigUint-backed fields).
