<objective>
Close the AVAIL-02 gap identified in 07-VERIFICATION.md: `post_input` still calls
`RsaBlindSigner::from_der_secret_key` on every request inside the write lock, negating
the per-round signer cache that AVAIL-02 was intended to provide.

Purpose: Eliminate the per-request RSA key deserialization from the input registration
hot path. An attacker sending parallel post_input requests currently forces RSA
deserialization under the write lock on each — this is the exact DoS vector the phase
was designed to close.

Output: `register_input` takes no signer param and accesses `inner.rsa_signer` directly.
`post_input` has no `from_der_secret_key` call and no `rsa_signing_key.clone()`.
</objective>
