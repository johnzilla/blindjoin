The canonical local command (per D-16 amended):

  BLINDJOIN_REQUIRE_BITCOIND=1 \
    BITCOIND_EXE=$(brew --prefix)/bin/bitcoind \
    cargo test --test integration 2>&1 \
    | tee target/integration-test.log

This is self-contained:
- BLINDJOIN_REQUIRE_BITCOIND=1 forces panic-on-miss (mirrors CI; surfaces a wrong BITCOIND_EXE path immediately)
- BITCOIND_EXE points cargo's integration tests at the brew-installed binary
- `cargo test --test integration` runs the integration test binary; the workflow-level CI command is `cargo test --workspace --all-targets` which includes integration. Local devs typically want just the integration suite, hence `--test integration`
- `2>&1 | tee target/integration-test.log` captures both streams to a file the dev can grep AFTER the suite finishes — avoids the documented pipe-hang pattern (TODO.md L47-55) because BitcoindGuard (Plan 09-02) kills bitcoind on drop and `view_stdout=false` (Plan 09-02) routes bitcoind's stdio to /dev/null. The tee is safe now.
