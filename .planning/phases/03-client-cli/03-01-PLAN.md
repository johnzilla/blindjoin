<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → coordinator HTTP | Untrusted coordinator responses (PSBT, blind sig, session token) |
| CLI args → wallet | User-provided descriptor strings, WIF keys, UTXO outpoints |
| PSBT content → signing decision | Coordinator-assembled PSBT could be tampered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | sign.rs PSBT verification | mitigate | CLI-04: count denomination outputs in PSBT; refuse if < participants_registered (Task 2) |
| T-03-02 | Tampering | wallet.rs key material | mitigate | bdk_wallet uses zeroize internally; BdkClientWallet does not log keys; WIF accepted only for testing |
| T-03-03 | Spoofing | Coordinator RSA key pre-commitment | accept | Already mitigated in Phase 1 (T-05-01): client verifies SHA-256(pk_der) == rsa_pubkey_hash before blinding |
| T-03-04 | Information Disclosure | --generate-wallet prints descriptors | mitigate | Print PROMINENT warning that descriptors are master private keys; write to descriptors.txt with 0600 permissions via std::os::unix::fs::PermissionsExt |
| T-03-05 | Elevation of Privilege | bdk_wallet descriptor from untrusted source | accept | Descriptor is CLI arg from local user; no network-sourced descriptor accepted |
| T-03-06 | Repudiation | No audit trail of what was signed | accept | CLI is single-shot; no persistent session; PSBT contains full tx for user review |
</threat_model>
