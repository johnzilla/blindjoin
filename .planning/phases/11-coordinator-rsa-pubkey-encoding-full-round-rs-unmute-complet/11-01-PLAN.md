<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| coordinator `/info` → client | Coordinator's RSA SPKI bytes cross from coordinator process → HTTP wire → client process. The bytes are integrity-bound by `SHA-256(SPKI_bytes) == rsa_pubkey_hash` (D-02). |
| `BjPublicKey::from_*` (blind-rsa-signatures parser) | Untrusted bytes (the `pk_der` Vec<u8>) cross into a cryptographic parser. The parser is the only thing standing between bad bytes and a key the client will then trust to blind a message and verify a signature. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | `client/src/round/input.rs:23-38` (hash-commitment block) | mitigate (PRESERVED — not introduced by this plan) | The pre-existing block hashes `pk_der` BEFORE the parse and rejects mismatch.
