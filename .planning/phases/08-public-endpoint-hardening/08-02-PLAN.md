<objective>
Wave 2 (parallel with Plan 03). Builds the per-route rate-limit + uniform request-timeout middleware that wraps the coordinator's HTTP API. This is the **DoS-resistance work product** of Phase 8 — the routes from `coordinator/src/api/mod.rs` start returning HTTP 429 with `Retry-After` when flooded (per CONTEXT D-03) and HTTP 408 when handlers stall past `request_timeout_secs` (per CONTEXT D-04).

Purpose: Mitigate volume-based DoS and slow-loris attacks against the publicly exposed HTTP endpoints (CONTEXT D-01 framing). Plan 03 separately handles the connection-count cap; Plan 04 adds the integration test that proves both behaviors end-to-end.
Output: `middleware.rs` factory functions returning composable tower layers; `mod.rs` Router builder wired with per-route `GovernorLayer` instances + Router-scope `TimeoutLayer` + existing `RequestBodyLimitLayer` (composed via `ServiceBuilder` to avoid the Pitfall 3 ordering trap).
</objective>
