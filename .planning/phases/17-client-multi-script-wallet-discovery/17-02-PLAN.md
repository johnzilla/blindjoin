**CONTEXT D-69 wire-shape correction (load-bearing — RESEARCH Pitfall 1):**

CONTEXT.md §D-69 literally says: `build_v2_psbt_input(signed) -> Result<bitcoin::psbt::Input>` and shows `B64.encode(bitcoin::consensus::serialize(&psbt_input))`. **THIS IS WRONG BY ONE ENVELOPE LAYER.**

The coordinator's decoder at `coordinator/src/bitcoin/utxo.rs:212-225` (function `decode_psbt_input_witness`) calls `bitcoin::psbt::Psbt::deserialize(&bytes)` expecting a **FULL BIP-174 PSBT** (one input, zero outputs). `bitcoin::consensus::serialize(&psbt::Input)` produces a different byte stream and would not roundtrip; `psbt::Input::serialize` (the BIP-174 key-value form) lacks the PSBT global header (magic bytes `0x70 0x73 0x62 0x74 0xff`) that `Psbt::deserialize` requires.

**Source of truth:** `tests/integration/multi_script_validate.rs:56-74::build_v2_psbt_input_b64` (Phase 16-02 LANDED) — a CANONICAL working encoder that the coordinator's decoder accepts in production tests. Phase 17 17-02 MUST mirror that helper VERBATIM (extended with `final_script_sig` population for P2SH-P2WPKH).

**The helper signature this plan creates** is therefore:
```
fn build_v2_psbt_input_b64(
    witness: &bitcoin::Witness,
    final_script_sig: Option<&bitcoin::ScriptBuf>,  // Some for P2SH-P2WPKH; None for P2WPKH/P2TR
) -> anyhow::Result<String>
```
NOT `-> Result<bitcoin::psbt::Input>`. The return is a `String` of base64-encoded `Psbt::serialize()` output.

**File anchors for executor:** read `tests/integration/multi_script_validate.rs` lines 56-74 (the canonical encoder) and `coordinator/src/bitcoin/utxo.rs` lines 212-225 (the canonical decoder) BEFORE writing the new helper in `client/src/round/input.rs`.

fn decode_psbt_input_witness(b64: &str) -> Result<Witness, Bip322Error> {
    let bytes = B64.decode(b64).map_err(|e| Bip322Error::DecodeError(format!("base64: {e}")))?;
    let psbt = bitcoin::psbt::Psbt::deserialize(&bytes)
        .map_err(|e| Bip322Error::DecodeError(format!("psbt: {e}")))?;
    let input = psbt.inputs.first().ok_or_else(|| Bip322Error::WireFormatMismatch("v2 PSBT envelope contains zero inputs".into()))?;
    let witness = input.final_script_witness.clone().ok_or_else(|| Bip322Error::WireFormatMismatch("v2 PSBT input lacks final_script_witness".into()))?;
    Ok(witness)
}

fn build_v2_psbt_input_b64(witness: &Witness) -> String {
    use bitcoin::psbt::Psbt;
    use bitcoin::{absolute, transaction, OutPoint, ScriptBuf, Sequence, Transaction, TxIn};
    let unsigned_tx = Transaction {
        version: transaction::Version(2),
        lock_time: absolute::LockTime::ZERO,
        input: vec![TxIn {
            previous_output: OutPoint::null(),
            script_sig: ScriptBuf::new(),
            sequence: Sequence::ZERO,
            witness: Witness::new(),
        }],
        output: vec![],
    };
    let mut psbt = Psbt::from_unsigned_tx(unsigned_tx).expect("unsigned tx -> psbt");
    psbt.inputs[0].final_script_witness = Some(witness.clone());
    B64.encode(psbt.serialize())
}
