<objective>
CI hygiene sweep: clear one closeable Dependabot advisory and pre-empt the June 2026 Node 20 deprecation in GitHub Actions.

Purpose:
- RUSTSEC-2026-0097 (rand 0.8.5 unsoundness when a custom logger calls `rand::rng()` mid-call) is fixed in 0.8.6. The current ignore in `.cargo/audit.toml` documents that blindjoin's logging stack (tracing + tracing-subscriber) never triggers the attack precondition — so the ignore is structurally safe, but it's still cleaner to remove the advisory entirely by bumping past it. This also closes 3 duplicate Dependabot alerts.
- GitHub Actions will hard-fail Node 20 actions in June 2026. The latest `actions/checkout@v6.0.2` (which we have *not* yet upgraded to — that's a separate deferred verification pass tracked in the ci.yml TODO comment) still declares `using: node20`. Setting the `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24` env var at the workflow level forces the runner to execute node20-targeted JS actions on Node 24, clearing the deprecation warning and inoculating against the June 2026 cutover *without* needing to bump action versions in this PR.

Output: lockfile bump, audit-config prune, three workflow env additions.
</objective>
