## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maintainer's YubiKey OpenPGP applet → host gpg-agent → `gpg --export --armor` output | Private key material never crosses back to the host. The exported `.asc` file is the public-key half only. |
