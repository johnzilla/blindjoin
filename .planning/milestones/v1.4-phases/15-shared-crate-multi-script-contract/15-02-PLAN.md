<objective>
Split shared/src/bip322.rs into the four-file directory module (mod.rs + p2wpkh.rs + p2tr.rs + p2sh_p2wpkh.rs) per D-04, land the dispatcher-only public API (ScriptType, Bip322Error, detect_script_type, verify_simple, sign_simple) per D-27, port the 26-LOC bip322 crate adapter from Sprint-0-A:145-175 verbatim per D-26, delete the coordinator-local Bip322Error per D-29, and add the bip322 = "=0.0.10" CI grep gate per Phase 14 carry-forward constraint #3.

Purpose: Establish the shared/ crate as the single source of truth for BIP-322 multi-script verification. The dispatcher-only public surface makes V1.4-CRIT-01 (script-type spoofing at the API layer) statically unreachable — callers cannot bypass dispatch because no per-script pub fn exists. The 26-LOC adapter is the entire integration contract with the bip322 crate; sighash, Schnorr-branching, and HASH160 cross-checks are handled by the crate per BIP322-02.

Output: Green `cargo test -p shared --lib`, green `cargo build --workspace`, green `cargo test --test full_round` (cross-phase invariant), and a CI bip322-pin-check job that fails any PR which drifts from `bip322 = "=0.0.10"`.
</objective>

26-LOC adapter (per CONTEXT D-26 / Sprint-0-A:145-175 / RESEARCH Pattern 2):

  pub(crate) fn verify_via_bip322_crate(
      spk: &bitcoin::Script,
      witness: &bitcoin::Witness,
      message: &[u8],
      network: bitcoin::Network,
  ) -> Result<(), Bip322Error> {
      let address = bitcoin::Address::from_script(spk, network)
          .map_err(|source| Bip322Error::UnrecognisedScriptPubkey { source })?;
      bip322::verify_simple(&address, message, witness.clone())
          .map_err(|source| Bip322Error::CrateVerifyFailed { source })
  }
