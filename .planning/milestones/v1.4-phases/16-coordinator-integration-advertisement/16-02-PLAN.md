> The coordinator MUST derive `ScriptType` from `txout.script_pubkey` (the on-chain SPK fetched via Bitcoin Core's `gettxout`) and MUST NOT trust the client-supplied `proof.script_type` field as authoritative. The client field is consulted ONLY as a defense-in-depth cross-check: if `declared != derived`, reject with `Bip322Error::ScriptTypeMismatch` BEFORE invoking `verify_simple`.

This invariant lives at TWO code locations (one per version branch of the validate_utxo dispatcher). The CI grep gate enforces that BOTH `// CRIT-01:` comments remain in place forever. A future PR that drops either comment fails the gate.
