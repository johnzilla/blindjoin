## Open release work

The actual `v1.6.0` git tag has not yet been cut. The release-ship sequence:

1. Dispatch `.github/workflows/reproducible-verify.yml` from the Actions tab on the branch you'll tag from.
2. Copy the `Rebuilt locally:` sha256 from the workflow log.
3. Paste it into the workflow's `EXPECTED_SHA256:` env and into the `v1.6.0` row in `docs/REPRODUCIBLE-BUILD.md`. Commit.
4. `git tag -s v1.6.0 -m "v1.6.0"` + `git push --tags`. The `release.yml` workflow fires automatically.
5. Run the pre-flight `cosign verify-blob` from `docs/RELEASING.md`.

This sequence is documented inline in `docs/RELEASING.md`.
